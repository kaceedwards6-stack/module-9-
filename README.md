# Module 9 Assignment 1 — Recursion (Towers of Hanoi)

Java project for the 3-disc Towers of Hanoi problem.

## Files

- `Towers.java` — recursive implementation.
- `Runner.java` — creates a Towers object for three discs.

## Running

```bash
javac Towers.java Runner.java
java Runner
```

## Expected output

```text
Move a disc from peg 1 to peg 3
Move a disc from peg 1 to peg 2
Move a disc from peg 3 to peg 2
Move a disc from peg 1 to peg 3
Move a disc from peg 2 to peg 1
Move a disc from peg 2 to peg 3
Move a disc from peg 1 to peg 3
```
